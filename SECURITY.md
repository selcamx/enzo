# Security policy

## Supported versions

Security fixes go into the latest release of Enzo. The app updates itself, and
the current version is always at [tryenzo.ai](https://tryenzo.ai) and on the
[releases page](https://github.com/selcamx/enzo/releases/latest).

## Reporting a vulnerability

Please report it privately, and don’t open a public issue.

- Email **hello@tryenzo.ai** with “Security” in the subject line.

Tell us what you found, how to reproduce it, and which version of Enzo and macOS
you were on. Leave out other people’s data.

We’ll acknowledge your report within 48 hours, keep you posted while we work on
it, and credit you in the release notes if you’d like.

## Scope

The Enzo app for Mac, tryenzo.ai and Enzo’s account service. Enzo’s source code is
private, so this repository holds only releases, their notes and the issue tracker.
